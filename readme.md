# 資料科學與大數據分析｜公開 AI 協作課程網站

本資料夾是 GitHub Pages 正式網站根目錄。網站採靜態架構，所有網站路徑使用相對位置；請勿加入 C:/、D:/、E:/ 等本機絕對路徑。

## 固定命名規則

所有網站檔名與資料夾名稱一律使用英文小寫、不要空格。

每週教材放在：

- `materials/week01/`
- `materials/week02/`
- …
- `materials/week18/`

每週固定檔名：

- 教師授課簡報：`slides.pptx`
- 學生空白學習單：`worksheet.docx`
- 若該週有資料集：`dataset.csv`

### Windows 重新命名提醒

如果 Windows 已設定「隱藏已知檔案類型的副檔名」，重新命名時畫面上可能只需要輸入 `slides` 或 `worksheet`。請務必確認實際檔名不是：

- `slides.pptx.pptx`
- `worksheet.docx.docx`

最安全的方式是先在檔案總管開啟「顯示副檔名」，再重新命名。

## PowerPoint / Word 的線上瀏覽方式

網站中的 PPTX 與 DOCX 按鈕會在新分頁使用 Microsoft Office Online Viewer 開啟，因此上課時不需要先下載到教室電腦。

這個功能必須等網站部署到 GitHub Pages、教材檔案具有公開 `https://` 網址後才會完整運作。直接從 Windows 雙擊 `index.html` 以 `file://` 開啟時，Microsoft 的線上檢視器無法讀取您電腦中的本機檔案，這是正常限制，不代表網站路徑錯誤。

## TronClass

公開網站只保留「正式作業與個人學習成果請至 TronClass 繳交」文字，不放 TronClass 超連結，也不在公開網站存放學生作答、成績、個別回饋或個資。

## GitHub Pages 更新原則

若教材維持相同檔名與路徑，日後只要覆蓋對應檔案並提交到 GitHub，不需要修改網頁程式。
